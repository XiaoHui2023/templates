# clock_tree

本族面向芯片时钟树在验证环境中的建模与观测：从晶振、PLL、分频、门控到末端时钟，用统一节点类型与驱动关系描述整棵树，并可在仿真中用 UVM 序列一次性拉起。

- 声明时钟源、分频、门控、二选一、反相、PLL、纯连线等节点，并为每个节点绑定设计里的时钟信号层次路径
- 每个节点附带 hardware interface，在仿真中测量频率与占空比，并给出活动与周期稳定指示；可按全局限定检查占空比是否在合格区间
- 图类型按声明创建全部节点，把各节点的驱动源接到对应句柄；多路选择用键区分不同输入
- 树项在随机化前由 manifest 建齐节点队列，并把标签、层次路径、典型频率等写入各节点，便于在外部 sequence 中持有树项并批量配置
