# 目录

路径由 `<路径段>/` 串联；含 `models.py` 的目录即一个可单独配置的模板单元。该目录下常见文件如下。

```text
<路径段>/<路径段>/…/<模板单元>/
  models.py              # 字段与类型；末尾 class 一般为 Models
  example.yaml           # 示例输入
  README.md              # 该单元配置字段
  <名字>.<后缀>.j2       # 源文件，如 foo.sv.j2；根目录与子目录内均可有
  <子目录>/              # 可有更多源文件与子目录
```
