# config_reg

写寄存器

## req

| 成员 | 说明 |
| --- | --- |
| **tree** | 时钟树 |
| **quiet** | 静默打印 |

## 流程

1. 随机化 tree。
2. 配置 **PLL** 并等待 lock。
3. 配置 **div**、**dto**、**inv**。
4. 写入 **gate** 与 **mux**。

## 细节

### 不重复配置

| 节点 | 何时跳过 | 做法 |
| --- | --- | --- |
| **pll** | 参考频率与输出频率不变 | 跳过配置 |
| **mux** | **sel** 不变 | 跳过配置 |
| **div** | **ratio** 不变 | 跳过配置 |
| **dto** | 每次配置 | 以 **load** 当前值为准产生上升沿；若 **load=1** 则先写 0 再写 1 |
| **gate** | **open** 不变 | 跳过配置 |
