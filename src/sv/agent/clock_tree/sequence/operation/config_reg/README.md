# config_reg

随机化时钟树目标并应用全部有效寄存器配置。tree 必须已经 build，sequencer 必须提供寄存器工具。

## req

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| **tree** | **tree_base** | 时钟树 |
| **quiet** | **bit** | 静默打印 |

## 流程

1. 校验请求、tree 和寄存器工具。
2. randomize tree，得到本轮频率、开关、选择和分频目标。
3. 打印没有任何 **clk** 下游的控制器件。
4. 配置需要变化的 **PLL**，再等待已配置且带 lock 寄存器的 **PLL** 锁定。
5. 配置有效的 **div**、**dto** 和 **inv**。
6. 配置应打开的 **gate**，写入 **mux** 选择，再配置应关闭的 **gate**。
7. 返回成功结果。

## 设计

### 不重复配置

| 节点 | 跳过条件 |
| --- | --- |
| **pll** | 参考频率、输出频率和开关状态已匹配 |
| **mux** | **sel** 已匹配 |
| **div** | **ratio** 已匹配 |
| **gate** | **open** 已匹配 |

**dto** 每次产生一次 load 上升沿，不能按 ratio 相同直接跳过。

### mux 配置

配置 **mux** 前写入本轮应打开的 **gate**。解析频率不是 RTL 活动证明，因此不根据解析频率推导切换等待。

### 失败边界

randomize 失败、PLL 配置非法或 lock 超时都会终止 operation。普通节点配置错误不通过 response 延后处理。

## rsp

| --- | --- | --- |
