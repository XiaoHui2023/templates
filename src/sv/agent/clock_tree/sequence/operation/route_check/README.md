# route_check

通过前级输出驱动和后级输入采样检查器件之间的 RTL 连线。tree 必须已经 build，并至少有一条两端接口完整的连线。

## req

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| **tree** | **tree_base** | 时钟树 |
| **quiet** | **bit** | 静默打印 |
| **debug** | **bit** | 强制打印开始信息 |

## 流程

1. 校验请求和 tree，执行一次 low_power 配置。
2. 根据普通 **source** 和 **mux** 全部输入收集有下游连线的前级节点。
3. 按前级输出分组，并行启动各组检查。
4. 将前级输出驱动为 0，检查该输出的全部后级输入。
5. 将前级输出驱动为 1，再次检查全部后级输入。
6. 释放前级输出，汇总检查、跳过和失败数量。
7. 全部组完成后返回结果；没有实际检查任何连线时终止 operation。

## 设计

### 扇出分组

同一个前级输出只驱动一次并检查全部扇出，避免对同一信号重复 force。不同前级输出并行，每个并行任务在创建时固定循环索引。

### 跳过与错误

任一端缺少接口时跳过该连线并打印原因。0 或 1 不一致使用 **UVM_ERROR** 记录，释放驱动后继续其它组；请求、tree、工具无效或没有可检查连线时终止 operation。

### 配置边界

low_power 只在开始时执行一次，随后不再 randomize 或写寄存器。PLL 与 stable 路径和其它节点一样参与连线检查。

## rsp

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| **ok** | **bit** | 全部已检查连线通过 |
| **failed** | **int** | 失败连线数 |
