# route_check

通过前级输出驱动和后级输入采样检查器件之间的 RTL 连线。tree 必须已经 build，并至少有一条接口完整的结构边；其它节点接口可以不连接。

## req

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| **tree** | **tree_base** | 时钟树 |
| **quiet** | **bit** | 隐藏开始和汇总信息 |
| **debug** | **bit** | 强制打印开始信息 |

## 流程

1. 校验请求和 tree，执行一次 low_power 配置。
2. 根据普通 **source** 和 **mux** 全部输入收集有下游连线的前级节点。
3. 按前级输出分组，并行启动各组检查。
4. 将前级输出驱动为 0，检查该输出的全部后级输入。
5. 将前级输出驱动为 1，再次检查全部后级输入。
6. 释放前级输出，汇总检查、跳过和失败数量。
7. 全部组完成后逐项确认每个前级均产生检查或跳过结果；无结构边或全部缺接口时报错。

## 设计

### 扇出分组

同一个前级输出只驱动一次并检查全部扇出，避免对同一信号重复 force。不同前级输出并行，每个并行任务在创建时固定循环索引；专用外层进程用 **wait fork** 汇合，不共享完成计数器，也不等待 operation 之外的进程。

**clk/cell** 只有一个 path，同一 interface 同时作为输入和输出；cell 位于链路中间时可以继续检查其下游连线。

### 跳过与错误

每条连线固定打印一次 **test** 或 **skip**，不打印 force 0/1 的过程值。任一端缺少接口时跳过，并说明缺少 source out、sink in 或两者。部分跳过不影响其它连线；全部缺接口或没有任何 **source/to_source** 结构边时终止 operation。任一前级没有产生 checked/skipped 结果也会终止，不能由其它成功组掩盖。0 或 1 不一致使用 **UVM_ERROR** 记录，释放驱动后继续其它组；请求、tree 或工具无效时同样终止 operation。

### 配置边界

low_power 只在开始时执行一次，随后不再 randomize 或写寄存器。PLL 与 stable 路径和其它节点一样参与连线检查。

| **failed** | **int** | 失败连线数 |
