# flip_check

在器件输入端施加独立激励，检查寄存器控制下的器件输出功能。tree 必须已经 build，候选器件需要完整接口和寄存器绑定。

## req

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| **tree** | **tree_base** | 时钟树 |
| **quiet** | **bit** | 隐藏开始和汇总信息 |
| **debug** | **bit** | 强制打印开始信息 |

## 流程

1. 校验请求和 tree，执行一次 low_power 配置。
2. 收集 stable 时钟及其结构上游，筛除这些器件和无有效时钟下游的控制器件。
3. 按候选顺序逐个测试器件。
4. 在当前器件输入端施加固定激励，配置寄存器，再测量或采样输出。
5. 释放当前器件输入驱动后测试下一个器件，最后汇总结果。

## 设计

### 器件检查

| 器件 | 检查内容 |
| --- | --- |
| **gate** | 1 GHz 输入下分别检查打开有频率、关闭无活动 |
| **div** | 1 GHz 输入下逐 bit 写 **f_div** one-hot 编码并检查对应输出频率 |
| **dto** | 1 GHz 输入和 ratio 4 下检查 250 MHz 输出 |
| **mux** | 首路为 900 MHz，后续输入逐路约降低 5%，遍历全部选择值并核对输出频率 |
| **inv** | 按 **inv_reg_high_means_inverted** 极性遍历直通、反相配置和输入 0/1 |

**div** 位宽由绑定的 **f_div** 自动获取；bit **i** 写入编码 **1 << i**，对应 ratio 为 **2 的 i 次方加 1**。每个 bit 配置都先产生 div 复位脉冲，再写分频值和 load。期望频率低于 **min_freq_hz** 时该 bit 报错。**dto** 使用代表 ratio 验证功能。PLL 不做功能检查，每个 PLL 打印 skip。

**mux** 写选择寄存器后固定等待 70ns，再开始输出测量。该等待用于避开切换瞬态；频率测量仍按输入频率等待稳定边沿。

频率激励按期望值生成；活动检测下限取期望频率减去允许误差。最低频率只控制等待时限，不参与周期样本筛选。

### 串行与寄存器

器件严格串行测试。已施加的输入 force 在寄存器切换期间保持，完成当前器件的全部检查后统一释放；随后才测试下一个器件。与 stable 支路共用控制字段的器件直接跳过。

### 跳过、清理与错误

每个候选器件固定打印一次 **test** 或 **skip**，不打印寄存器逐值翻转过程。stable 时钟上游、无效控制器件、缺接口或缺寄存器的器件跳过并打印原因。任一器件没有产生唯一的 check/skip 状态时终止 operation。器件错误使用 **UVM_ERROR** 累计，释放当前输入后继续；请求、tree、工具无效或没有可用候选时同样终止 operation。
