# check_measure

按时钟树解析结果检查 **clk/cell** 是否有时钟，再按需检查频率和 **clk** 占空比。tree 必须已经 build，且至少选择 **clk/cell** 一类节点。

## req

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| **tree** | **tree_base** | 时钟树 |
| **quiet** | **bit** | 静默打印 |
| **debug** | **bit** | 打印未完成节点和测量阶段 |
| **check_clk** | **bit** | 检查 **clk** |
| **check_cell** | **bit** | 检查 **cell** |
| **check_freq** | **bit** | 活动检查通过后检查频率 |
| **check_duty** | **bit** | 活动检查通过后检查占空比 |
| **min_freq_hz** | **int** | 测量最低频率；0 使用全局值 |
| **skip_nodes** | **node_base** 队列 | 跳过的节点 |

## 流程

1. 校验 tree 和检查开关，收集带测量接口且未跳过的 **clk/cell**。
2. 按最低频率计算活动确认与可选稳定测量的总超时。
3. 启动本轮需要的测量；共享同一接口的节点只启动一次。
4. 先检查实际有无时钟是否符合 `_resolved_active`。
5. 仅对期望且实际均 active 的节点，按开关检查频率和占空比。
6. 测量接口意外停止且节点仍未完成时，最多重启一次。
7. 总超时后判定全部未完成项目并记录失败节点。
8. 最后一个使用者完成后停止测量，返回汇总结果。

## 设计

### 检查边界

活动检查始终执行，不受 **check_freq/check_duty** 影响。**cell** 不检查占空比；**clk** 仅在请求和节点自身都允许时检查占空比。期望 inactive 的节点只确认没有活动，不检查频率和占空比。

### 共享接口

多个节点引用同一接口时共用一次测量状态；只有该接口关联的节点全部完成后才停止，避免一个节点提前关闭其它节点仍在使用的测量。

### 超时与错误

活动和稳定超时各保留一个 **1ns** 轮询步长，稳定超时另保留一个频率基准周期，避免边沿与超时进程在同一时刻竞争。节点错误使用 **UVM_ERROR** 记录并继续检查，其节点在 **failed_nodes** 中只保留一次；请求、tree 或检查目标无效时终止 operation。

## rsp

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| **ok** | **bit** | 全部节点通过 |
| **failed_nodes** | **node_base** 队列 | 失败节点，已去重 |
