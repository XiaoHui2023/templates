# test_flip

检查单个器件的寄存器功能。

## 输入

| 节点 | 端口 |
| --- | --- |
| gate / div / dto / inv | **in_path**、**out_path** |
| mux | **in_paths**、**out_path** |

缺少当前器件所需端口或寄存器时跳过该器件并打印原因。

## 流程

1. 执行 **low_power** 并写入配置。
2. 在当前器件 **in** 端制造时钟激励。
3. 修改当前器件寄存器。
4. 测量当前器件 **out**。
5. 按器件功能判断结果。
6. release 当前器件 **in**。

PLL 不做功能测试。

## 激励

| 器件 | 激励 |
| --- | --- |
| gate | 单输入 100MHz |
| div / dto | 单输入 800MHz |
| mux | 每个输入不同频率 |
| inv | 单输入 200MHz |
